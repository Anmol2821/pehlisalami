SSB practice

Five days. Every test. Board timing.

Screening is on the first morning: OIR and PPDT. Only screened-in candidates stay for psychology, GTO and the interview, which test the same officer-like qualities from three sides. Each test has a "Skip ahead" button for trying the format quickly.
